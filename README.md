# 텔레그램 홀덤 딜러 봇

그룹 채팅방에 초대하면 노리밋 텍사스 홀덤을 진행하는 딜러 봇입니다.
베팅·보드·결과는 그룹방에, **각자의 패는 개인 메시지(DM)로** 전달됩니다.

## 1. 봇 만들기 (BotFather)

1. 텔레그램에서 `@BotFather` → `/newbot` → 이름/아이디 입력 → **토큰** 복사
2. `/mybots` → 봇 선택 → *Bot Settings* → *Allow Groups?* 가 **Enabled** 인지 확인
3. **한글 단축키를 쓰려면** `/setprivacy` → 봇 선택 → **Disable** (또는 봇을 그룹 관리자로 지정)
   텔레그램은 영문 명령어(`/join`)만 "명령어"로 인식합니다. `/ㄹㄷ` 같은 한글 단축키는 일반 메시지로
   들어오므로, Privacy 모드가 켜져 있으면 봇에게 전달되지 않을 수 있습니다.
   설정 변경 후에는 봇을 그룹에서 내보냈다가 다시 초대해야 적용됩니다.

## 2. 실행

```bash
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env      # .env 를 열어 BOT_TOKEN 입력
.venv\Scripts\python bot.py
```

테스트: `.venv\Scripts\python -m pytest -q`

## 3. 게임 방법

먼저 각 플레이어가 봇과 1:1 대화에서 `/start` (또는 `/ㅎㅇ`) 를 한 번 눌러야 합니다.
봇은 먼저 말을 건 사람에게만 DM을 보낼 수 있습니다. 그 다음 그룹에서 `/join` → `/begin`.

| 분류 | 명령어 | 설명 |
|---|---|---|
| 👥 참가 | `/join` | 게임에 참가 (테이블이 없으면 기본 설정으로 자동 생성) |
| | `/leave` | 나가기 (핸드 중이면 폴드 처리 후 핸드가 끝날 때 퇴장) |
| | `/players` | 참가자 목록 |
| | `/rebuy` | 칩이 시작 스택 미만일 때 30,000 추가 (진행 중인 핸드에 참여 중이면 불가) |
| 🎮 진행 | `/begin` | 게임 시작 (2명 이상), 이후 핸드가 자동으로 이어짐 |
| | `/status` | 게임/로비 상태 |
| | `/stopgame` | 현재 핸드가 끝나면 중지 |
| 🃏 액션 | `/call` `/check` `/fold` `/allin` | 그룹 메시지의 버튼으로도 가능 |
| | `/raise 금액` | 해당 스트릿 **총 베팅액** 기준 (예: `/raise 1000`) |
| ⚙️ 설정 | `/blinds SB BB` | 예: `/blinds 200 400` — 핸드 중이면 다음 핸드부터 적용 (참가자/관리자) |
| | `/timer 초` | 액션 타임아웃 5~120초, 초과 시 자동 체크/폴드 |
| | `/newtable [스택] [SB] [BB]` | 설정을 지정해 테이블 생성 |
| | `/closetable` | 최종 칩 집계 후 종료 (만든 사람/관리자) |
| 🔍 기록 | `/hand` | 전판 내 패 확인 — 그룹에서 입력해도 **DM으로** 전송 |
| | `/open` | 전판 커뮤니티 카드를 리버까지 공개 (중간에 끝난 핸드의 남은 카드 포함) |

**⌨️ 한글 단축키**: `/ㄹㄷ` → `/join`, `/ㅂㅂ`·`/쉬야` → `/leave`, `/ㄱㄱ` → `/begin`, `/ㅎㅇ` → `/start`

그 외:
- **🃏 내 패 보기** 버튼 — 누른 사람에게만 보이는 팝업으로 패와 현재 족보 표시
- DM에서 `/mycards` — 진행 중인 내 패 다시 보기
- `/join` 시 봇이 DM을 보낼 수 없으면 착석시키지 않고 "봇과 대화 시작" 버튼을 안내합니다.

## 4. 규칙 구현 범위

- 최대 9인, 헤즈업 블라인드 규칙(버튼 = SB, 프리플랍 선 액션)
- 최소 레이즈, 숏 올인(불완전 레이즈)은 이미 액션한 플레이어에게 리레이즈를 다시 열지 않음
- 메인/사이드 팟, 콜되지 않은 베팅 반환, 분할 팟(홀수 칩은 버튼 왼쪽부터)
- 칩을 모두 잃으면 자리는 유지된 채 딜에서 제외 — `/rebuy` 로 다시 참여 (연습용 칩)
- 셔플은 OS 난수(`random.SystemRandom`) 사용

## 5. 구조

```
holdem/cards.py      카드·덱
holdem/evaluator.py  7장 중 최고 5장 족보 판정
holdem/game.py       테이블 상태머신 (텔레그램 의존성 없음)
bot.py               텔레그램 핸들러 (그룹 진행, DM 패 전송, 타이머)
tests/               엔진 테스트 + 가짜 텔레그램 객체로 봇 흐름 테스트
```

## 제한 사항

- 게임 상태는 **메모리에만** 저장됩니다. 봇을 재시작하면 진행 중인 테이블이 사라집니다.
- 쇼다운 시 남아있는 모든 플레이어의 패를 공개합니다(머크 선택 없음).
- 한 프로세스로 실행하는 것을 전제로 합니다(여러 인스턴스 동시 실행 불가).
